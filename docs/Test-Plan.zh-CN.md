# 测试计划

[English](Test-Plan.md) · [简体中文](Test-Plan.zh-CN.md)

## 测试层

1. **Dart 单元与 widget：**四个底部导航页、系统及显式语言选择与回退、设置中的运行模式、MCP 总开关、Root 授权入口显隐、自动权限开关警告和持久化、Root 状态、权限与无障碍摘要、令牌表单校验和错误呈现。
2. **Kotlin 单元：**令牌哈希与验证、有效期、一次性令牌原子消费、独立工具允许列表、只读默认值、`shell_exec` 默认关闭、物理删除、能力注册表和请求限制。
3. **协议集成：**HTTP 状态码、`WWW-Authenticate`、MCP ping/server-discover/initialize/tools/list/tools/call、错误 JSON-RPC 和服务关闭状态。
4. **调试页面：**静态页面加载、令牌仅驻留内存、按 schema 发现工具、工具按钮发送正确的 `tools/call`、独立历史/状态/结果区域、HTTP 状态与耗时、图片呈现、日志脱敏与最多 50 条、视口适配与滚动、可选 UI 树和边界框、路径可读性、红色选中框、子元素优先命中、树行自动滚动、JSON 路径、XML XPath、属性、边界和中心点击。
5. **设备集成：**Root 可用、不可用和拒绝状态，API 版本矩阵，截图、Shell、输入、应用启动、进程终止和重启。
6. **LAN 安全：**显式启用 MCP、本地网络权限拒绝、令牌删除、工具过滤、明文/TLS 策略、并发请求和广播地址校验。
7. **后台及权限集成：**前台服务通知与应用退后台、可恢复重启、Root 不可用/超时、权限成功/已授予、签名和特殊访问权限拒绝；结果只逐项显示失败权限。
8. **UI 检查集成：**已启用的 ARMCP 无障碍服务快照、活动窗口选择、尽力刷新节点、动态子节点失效、最近完整快照重试、已连接但不可读诊断、无 ARMCP 层级字节上限、XML/JSON 格式、中心坐标、内容过滤、Root 回退冲突和 Android 15 `already registered` 诊断，包含淘宝等动态窗口。
9. **XPath 随机输入：**合法与非法 XPath、缺少边界、无障碍和 Root 快照、`/dev/hwrng` 不可用或读取失败、在 `[left, right) × [top, bottom)` 内均匀拒绝采样、有界输入注入，且不使用软件伪随机回退。
10. **运行模式、无障碍及 TalkBack：**Root/非 Root 持久化、Root 专属状态和权限控件、非 Root 设置引导、切换偏好不立即启动服务、截图确认后的临时 TalkBack 重试与精确恢复、TalkBack 已启用时保持状态、空/不可读截图不触发，以及手势/文本能力错误。
11. **导航和环境：**主页显示原生边界、Root、非无障碍权限、无障碍和 MCP 状态；运行支持页随模式变化；Root 可用后隐藏授权入口；设置保存模式和语言。

## 必需夹具

- Root 执行器模拟：可用、不可用、拒绝、超时和格式错误输出。
- 精确控制过期边界的假时钟。
- 调试页面测试用的 MCP HTTP 假服务。
- 已脱敏的命令和截图夹具；不得提交真实密钥或个人设备内容。
- 仅含 manifest 权限名称和脱敏 `pm grant` 结果的权限夹具。

## 发布门槛

- 工具只有在注册表、schema、能力检查和针对性测试齐备后才能标为已实现。
- UI XML 检查覆盖 Root 不可用、超时、格式错误和成功层级，并返回后端/权限元数据。
- 成功结果验证 `view_tree` 返回可解析 XML、`view_content` 返回可解析 JSON，且 `tap.x`/`tap.y` 等于元素边界中心。
- 调试 UI 验证树行或边界框选中后共用详情面板、路径稳定、仅 XML 显示 XPath，中心点击发送选中坐标。
- LAN、无限期令牌、新令牌写操作及 `shell_exec` 均不得默认启用。
- 新令牌工具选择通过专用页面进行；主设置页不呈现完整工具开关列表。
- scaffold 提供相应命令后，`flutter analyze`、Flutter 测试、Android 单元/仪器测试和发布构建必须通过。
