# 产品愿景

[English](Vision.md) · [简体中文](Vision.zh-CN.md)

## 项目目标

构建一个由 Flutter 界面和 Android 原生代码组成的 APK。操作人员明确启用并配置认证后，APK 可在设备本地或局域网提供 MCP 服务，并由同一进程托管调试页面。

面向操作人员的产品名称为 **ARMCP（Android Root MCP）**，不改变 Android 应用身份。

## 原则

- **简洁：**一个 APK、一个原生 Android 边界、一个直接运行的 MCP 服务和一个调试页面来源，不增加桥接或代理。
- **原子化：**每次增加一个能力或工具，并定义输入、能力检查和针对性验证。
- **能力如实呈现：**Root 不可用、API 不支持或 UI 控制尚未验证时，明确展示状态，不静默降级。
- **最小暴露：**服务默认关闭，监听范围经过选择，并要求令牌认证。
- **后台可见：**服务启用期间由 Android 前台服务和持续通知显示运行状态，不隐藏运行行为。

## 非目标

- 自动获取 Root 或修改设备启动链。
- 声称 Root 控制对其他软件不可见。
- 构建通用远程管理平台。
- 添加第二个 MCP 服务端、桥接、代理、扩展或插件市场。
